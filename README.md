# 五线谱速认

给成人钢琴初学者的识谱练习工具。打开网页就能用，不用注册，也不用下载。

**在线试玩：** https://你的用户名.github.io/仓库名/

## 能练什么

**看谱识音**：谱上出现一个音符，尽快答出它是什么音。每题都会记录反应时间。答得慢的音和答错的音，下一轮会多出几次。

**听旋律写音**：先听一段旋律，再按顺序把每个音写出来，相当于音乐版的听力练习。答对的音会写到五线谱上。答错时会提示你选的音偏高还是偏低，并重播给你对比。

## 三档难度

| 难度 | 看谱识音 | 听旋律写音 |
|---|---|---|
| 入门 | 谱内音，没有升降号 | 小星星、欢乐颂、生日快乐等 6 首 |
| 进阶 | 加线音，G 大调和 F 大调，偶尔出现升降号 | 新年好、送别、友谊地久天长等 4 首，有大跳音程和调号 |
| 高级 | 2–3 个升降号的调，经常出现升降号 | 致爱丽丝、绿袖子、土耳其进行曲、卡农，有临时升降号 |

每轮结束后，如果正确率达到 90%、平均用时不超过 2 秒，会推荐进入下一阶段。

## 三种作答方式

- **选音名**：可以用 C D E，也可以用固定调或首调唱名 do re mi。
- **点琴键**：在屏幕上的钢琴键盘上点，要选对八度。
- **用真乐器**：连上 MIDI 键盘直接弹，或者对着麦克风弹、唱。麦克风模式可以设置忽略八度，方便唱歌的用户。

## 使用说明

- 建议用电脑上的 Chrome 或 Edge 浏览器。Safari 和微信里的浏览器不支持 MIDI 键盘。
- 手机上第一次打开时，需要先点一下屏幕，才会有声音。
- 麦克风的声音只在你自己的设备上分析，不会上传。游戏不收集任何个人信息。
- 个人最佳成绩保存在你的浏览器里，换设备或清除浏览器数据后会丢失。
